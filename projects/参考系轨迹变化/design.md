# 设计方案：参考系改变时，同一物体的运动轨迹如何变化

- 项目目录：`projects/参考系轨迹变化/`
- 课程定位：高中物理 · 必修一 · 第一章《运动的描述》——参考系（本节只讲参考系）
- 拟定输出：`out/参考系轨迹变化.mp4`（1280×720 / 30fps / H.264 + AAC / 纯白底 / 约 54 s，以 TTS 实测为准）
- 本文件是**阶段一交付物**：确认后才生成 animation.html 与分镜，再确认后才出片。

---

## 1. 教学目标与课程范围

**学生学完本片能做到：**

1. 说出参考系的含义：描述一个物体的运动，要先选定另一个作为参考的物体。
2. 观察同一个物理情境（无风时下落的雨滴），分别以地面和以匀速行驶的车厢为参考系，说出雨滴的**轨迹**分别是竖直直线和斜向后的直线。
3. 归纳本节结论：**参考系不同，同一物体运动的轨迹描述就不同；描述运动必须先指明参考系。**

**本片只处理"轨迹（运动的路径形状与方向）"这一个可观察量**，不涉及速度、位移、加速度、运动合成等后续内容，避免把后面章节的模型提前塞进本课。

## 2. 必要前置知识（本节默认学生已具备，片中只用不展开）

- 机械运动：物体位置随时间的变化（本章开篇已有）。
- 质点：当物体的大小、形状对研究问题影响很小时，可把物体看作有质量的点——本片把雨滴、站台上的人、乘客都按"点/简化示意"处理，不讨论雨滴形状。
- "参考系"这个词本身的含义：被选作参考标准的那个物体（本节核心，片中正面建立）。

## 3. 明确排除的超纲内容

| 排除项 | 原因 |
| --- | --- |
| 速度矢量、速度的合成与分解、`v_车 ± v_雨` 之类的相对速度计算 | 速度是本章第 3 节、运动合成是必修二内容 |
| 位移、位移–时间图像、加速度 | 位移是本章第 2 节，加速度是本章第 4 节 |
| 平抛、自由落体、竖直上抛等抛体模型 | 后续章节内容，本课不出现这些术语与规律 |
| 任何公式与物理量符号（不出现 `v`、`x`、`t` 的表达式） | 本课只做定性描述；KaTeX 公式层保留但本片不排公式 |
| 非匀速（加速）车厢中轨迹弯曲的讨论 | 涉及非惯性参考系，远超本课 |

旁白与画面用词统一为：**参考系、地面、车厢、雨滴、竖直、斜向后、轨迹**——不出现"分运动""合运动""水平速度""竖直速度"。

## 4. 教学逻辑与逐场景顺序

顺序即教学顺序：**课题 → 情境与两个参考系 → 逐一建立观察视角（先地面、后车厢，各自完整演示）→ 结尾并列对比 → 结论**。

主体过程中**任何时刻只演示一种情况**（地面视角一段、车厢视角一段，互不并列）；只有在两种情况都讲完之后，结尾用一段**短暂并列**做比较。

| 段 id | 场景 | 画面与运动方式 | 旁白要点 | 预计时长 |
| --- | --- | --- | --- | --- |
| title | 课题 | 白底 + 网格。主标题"参考系与运动的描述"，副标题"同一滴雨，两种轨迹"，蓝色分隔线随入场生长，底部一行小字"高中物理 · 必修一"。右侧两条微型轨迹示意（一条竖直、一条斜）淡入 | 提出本课问题：同一个物体的运动，换一个参考系来描述，轨迹会怎样变化？ | ≈6.9 s |
| setup | 情境与两个参考系 | 静态布置（只有卡片错峰入场，不做轨迹演示）：左侧"站台上的人 / 地面参考系"图示卡片，右侧"车厢里的乘客 / 车厢参考系"图示卡片，中间一枚放大的雨滴图标标注"同一滴雨、无风时竖直下落" | 交代情境：无风时雨滴相对地面竖直下落；站台上的人和车厢里的乘客，正以不同的参考系观察同一滴雨 | ≈10.5 s |
| ground | 情况一：地面参考系 | 镜头固定在地面。雨滴自上而下运动，**竖直轨迹逐点生长**成一条竖直直线（虚线辅助线 + 生长中的实心轨迹 + 到达点位置的水滴）；右上角常驻"参考系：地面"卡片，底部结论条"以地面为参考系：轨迹是竖直的直线"。作为情境延续，一列低对比度的车厢在背景中匀速驶过（不画它在车厢内的任何轨迹，避免形成第二个动态视角） | 以地面为参考系，雨滴沿竖直方向下落，轨迹是一条竖直的直线 | ≈7.4 s |
| train | 情况二：车厢参考系 | 镜头跟随车厢（车厢固定在画面中央，站台与地面的条纹匀速向后移动，提示"车厢在前进"）。乘客视角下，同一滴雨**一边下落、一边相对车厢向后退**，**斜向后的轨迹逐点生长**成一条斜直线（约 45°，由车厢速度与下落速度示意比例决定，不做计算）。右上角"参考系：车厢"卡片，底部结论条"以车厢为参考系：轨迹是斜向后的直线" | 以车厢为参考系，车厢不断向前，雨滴一边下落，一边相对车厢向后退，轨迹是一条斜向后的直线 | ≈10.7 s |
| compare | 结尾并列对比 | 全片唯一并列画面：左右两块小面板，左"地面参考系"显示竖直轨迹终态，右"车厢参考系"显示斜向后轨迹终态；两条轨迹轻轻重绘一遍（各 1 s 左右）后停住，下方一句"参考系不同 → 轨迹不同" | 同一个雨滴，在地面参考系里是竖直的直线，在车厢参考系里是斜向后的直线 | ≈8.7 s |
| outro | 本节结论 | 结论卡片：主句"参考系不同，同一物体运动的轨迹不同"，副句"描述运动，必须先指明参考系"；两条轨迹的极小图标作装饰，画面在结尾**停住** | 参考系不同，同一物体运动的轨迹就不同；所以描述运动，必须先说明以哪个物体为参考系 | ≈10.1 s |

`segDur = max(minDur, lead + 字数/cps + tail)`。**阶段三出片时改用 say 实测语音时长重算，不沿用预估数字。**

## 5. 多种情况的呈现方式（重要规则落实）

- **分开、逐一、完整演示**：地面参考系（ground 段）与车厢参考系（train 段）各自独立成段，各自从雨滴出现讲完一个完整过程；主体过程中屏幕上不存在第二个正在演示的视角。
- **同一时刻只有一种动态情况**：setup 段不做轨迹动态（只有标注入场）；ground 段的动态只有"竖直轨迹生长"（背景车厢仅为低对比度匀速平移，不产生任何车厢视角轨迹）；train 段的动态只有"斜向后轨迹生长"。
- **结尾短暂并列**：compare 段是唯一并列画面，出现在两种视角都讲完之后，只做终态对比与一次轻量重绘，不替代主体演示。

## 6. 交互与播放行为

- 打开 `animation.html` 后自动播放**一遍**，播完**停在结尾，不循环、不自动重播**；右上角提供"重播"按钮（手动）。
- 底部常驻 3 px 进度条，观众知道还剩多久；场景之间 0.5 s 交叉淡入（先画上一场景终态再叠加当前场景）。
- **阶段二的逐段语音预览**：页面内用浏览器 `speechSynthesis` 选默认中文系统音色（优先 `zh-CN`/`zh`），按 `script.json` 的段序逐段朗读，与场景逐段对应，读到哪一段就播哪一段的画面；提供明确的"播放讲解 / 重播讲解"控件（浏览器自动播放限制由用户点击启动），讲解结束即停止；页面标注"预览音色：浏览器内置中文语音（与成片音色不同）"。分镜截图时静音，不受影响。
- 画面每帧只依赖时间 `t`（纯函数式绘制，无随机、无累积状态），保证分镜与成片逐帧一致，并暴露 `window.__seek(t)` 与 `window.__VM`。

## 7. 画面规范

- 纯白底 `#ffffff` + 网格 `rgba(100,116,139,0.10)`，深墨字，强调色蓝 `#2563eb`（轨迹用蓝、车厢/站台用次墨 `#334155`、暖橙 `#f97316` 只用于高亮"同一滴雨"）；不加径向光晕。
- 卡片：白底 `rgba(255,255,255,0.95)` + 细描边 `rgba(15,23,42,0.12)` + 柔和投影 + 圆角 18。
- 中文标题与说明留在 canvas；本片**不使用 LaTeX 公式**（无公式可排），`vendor/katex/` 照常保留以便后续扩展。
- 术语写法与旁白念法完全一致（"斜向后"而非"斜向下后方"）。

## 9. 待确认的假设（请逐条过一眼）

1. **例子选无风下落的雨滴 + 匀速行驶的车厢**（人教版必修一参考系一节的经典情境），不引入抛体运动；车厢取匀速，故车厢参考系中的轨迹是一条**斜直线**而不是曲线。若希望改用其它情境（如车厢内小球的竖直往返运动、或站在车厢里看窗外的树），请指出。
2. **只描述轨迹，不做任何速度/位移的定量或矢量分析**，全片无公式。
3. 结尾保留 compare（并列对比，≈8.7 s）；若觉得多余可删，总时长随之减少。
4. ground 段背景中"驶过的车厢"保留还是去掉（保留能让两段情境连续，去掉画面更纯）。
5. 语速与音色用 `Sandy (中文（中国大陆）)` / rate 178 是否可以；也可以先听后换。
6. 项目建在 `projects/参考系轨迹变化/`，成品名 `参考系轨迹变化.mp4`，可改。
